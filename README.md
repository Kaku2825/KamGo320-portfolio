# 建筑学作品集 · Portfolio

在线个人作品集，纯静态站点：无框架、无构建步骤、无第三方运行时依赖。

**在线访问**：<https://kaku2825.github.io/KamGo320-portfolio/>

## 浏览方式

| 操作 | 效果 |
|---|---|
| 滚轮 ↓ / 点「进入作品集」 | 封面 → 作品索引（横向推进） |
| 悬停卡片 | 点亮 + 浮出作品名 |
| 点卡片 | 图框扩张：整页作品从卡片窗口扩至全屏 |
| 滚轮 / 拖拽 / 向左滑动 | 作品长卷无极滑动（带惯性） |
| `Ctrl`+滚轮 / 双击 / 双指捏合 | 当前页缩放 1–2.6×，放大后可拖拽平移 |
| `←` `→` / `Shift`+`←` `→` | 翻页 / 跨作品跳转 |
| 点底部轴段或刻度 | 跳到指定作品 / 指定页 |
| `Esc` / 「返回索引」 | 退出长卷，回到作品索引 |

## 结构

```
.
├── index.html        页面骨架：固定外框（标识 / 刻度 / 导航 / 四角信息）+ 板块舞台
├── css/main.css      全部样式
├── js/
│   ├── data.js       站点内容：个人信息、作品清单、配色、页面顺序
│   ├── main.js       板块推进 / 导航 / 刻度 / hash 路由
│   ├── cover.js      封面
│   ├── works.js      卡片阵列 + 横向长卷（拖动惯性 / 缩放 / 轴式指示条）
│   ├── about.js      关于页
│   └── utils.js      rAF 主循环 / 缓动
└── assets/
    ├── fonts/        自托管字体
    ├── cards/        索引卡片图
    └── pages/        作品整页图（WebP）
```

## 本地预览

```bash
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 部署

托管在 GitHub Pages：`main` 分支根目录，已含 `.nojekyll`，全部资源使用相对路径，可直接部署在子路径下。

```bash
git add -A
git commit -m "更新内容"
git push
```

推送后 Pages 约 30–60 秒自动重建。若改动了 `css/` 或 `js/`，请把 `index.html` 中对应的 `?v=` 版本号加一，避免浏览器命中旧缓存。

## 内容维护

文字与作品清单集中在 `js/data.js`：作品顺序、标题、每件作品的页面范围、配色（field / ink / hl）、板块开关。换图时替换 `assets/cards` 与 `assets/pages` 下的同名 WebP 即可。
